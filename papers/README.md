# papers/ — gather protocol

## Per-paper template (batch files: batch-NN.md)

```
### <ID>. <Title> — <Channel/Author> (<year>)
- Verified URL: <url> (verified <date> via <source of verification>)
- Verification level reached: metadata-verified | content-verified | teaching-grade
- Faithful summary: <what the source does, in the source's own logic>
- Decisive moves: <move 1> [P-ID] ; <move 2> [P-ID] ; ...
- Candidate new patterns: CAND-<n>: <name> — <shape/move> (fired/missed: <evidence>)
- Honest misses: <book patterns that did NOT fire here> (a miss is a datum)
- Feeds: <book chapters>
```

## Chunk rules
- Sub-chunks of ~3 papers; one commit per sub-chunk; extend, never rewrite batch files after commit.
- Dossiers in `patterns/` quote census/miss lines from batches; ANALYSIS.md is written from dossiers, never by re-reading batches.
- Promote a candidate when it fires across >= 2 batches (load-bearing recurrence test); record firings/misses per pattern.
- Nothing enters the book on any external source's own say-so — verification first.
